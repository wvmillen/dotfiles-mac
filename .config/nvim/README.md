# 💤 LazyVim

Use the command `:LazyExtras` to install lsp and such.
Use `:LazyHealth` for needed dependencies to be installed on your machine and other general troubleshooting.

Built on this distro [LazyVim](https://github.com/LazyVim/LazyVim).

Refer to the [documentation](https://lazyvim.github.io/installation) to get started building your own.
